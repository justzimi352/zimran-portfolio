WORK THUMBNAILS — how to add your reel covers
=============================================

Each card on the site looks for an image in this folder. Drop a cover
screenshot in with the EXACT filename below and it appears automatically.
Until a file exists, the card shows a polished cinematic placeholder — so
nothing ever looks broken.

  work-1.png  ->  Eid-ul-Azha Appreciation Reel
  work-2.png  ->  Debating Club — Introduction
  work-3.png  ->  Debating Club — Induction
  work-4.png  ->  CARDIG UCMD — Instagram
  work-5.png  ->  CARDIG.net

All five are now in place. To swap any of them later, just replace the
matching file (keep the same name) and it updates on the site.

TIPS
----
- Best size: roughly 1280 x 800 px (16:10), landscape.
- Keep files reasonably small (ideally under ~400 KB each) so the page
  stays fast on mobile. work-5.png is currently ~2.7 MB — worth compressing
  (e.g. tinypng.com) for faster loads.
